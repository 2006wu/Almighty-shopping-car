# 開發時程

目標展示為 12 × 10 公尺的小型模擬商店，恰好四排貨架與三條貨架間走道（各寬 1.6 公尺），包含入口與結帳區。

目前為 2026 年 10 月；2027 年 2 月前以模擬完成演算法與介面。負責範圍維持 SLAM、Nav2 與人物跟隨，其他組員的介面另行協調。

## 階段 0：骨架（2026 年 10 月）

- [x] 建立七個 ROS 套件、安裝設定、launch 與參數檔。
- [x] 建立雙容器、僅限本機的 noVNC 桌面、UDP DDS 設定與操作腳本。
- [x] 建立四輪車、小型模擬商店幾何、共用人物路徑及橋接設定。
- [x] 建立 SLAM、Nav2 與區域動作介面。
- [x] 建立 UWB 純邏輯、模擬節點、安全跟隨狀態與單元測試。
- [x] 加入四排／三走道與目標／人物完整路徑的碰撞淨空測試。
- [x] 支援 ROS apt 鏡像及受限網路建置參數。
- [x] 建立繁體中文架構、協作規範及進度紀錄。
- [ ] 在 Docker Desktop 完成映像建置與 ROS／Gazebo 冒煙測試。

## 階段 1：模擬啟動與商店建圖（2026 年 10–11 月）

- [ ] 確認 amd64／arm64 建置、雙容器 DDS、RViz 與 GPU 雷射的軟體繪圖。
- [ ] 確認 TF、時間、輪子方向、滑移、里程計與雷射座標。
- [ ] 遙控走遍三條走道與入口／結帳區，調整 slam_toolbox，儲存格網與位姿圖。
- [ ] 測試離線重新載入地圖與定位，核對區域座標。

## 階段 2：Nav2 與區域引導（2026 年 11 月）

- [ ] 調整 DWB、足跡、膨脹距離與速度平滑。
- [ ] 驗證六個區域與中文別名、動作拒絕／失敗／取消。
- [ ] 驗證窄走道、結帳區、人員穿越與 AMCL 替代定位。

## 階段 3：UWB 模擬跟隨（2026 年 11–12 月）

- [ ] 比較兩錨點與三錨點，記錄前後歧義與幾何配置的誤差。
- [ ] 掃描測距噪聲、偏差、NLOS 機率、掉包率與更新頻率。
- [ ] 確認人物幾何與 UWB 真值路徑同步、模型位姿橋接正確。
- [ ] 評估濾波延遲、轉彎跟隨、近距停止與重新取得目標。

## 階段 4：模式、安全與恢復（2026 年 12 月）

- [ ] 實作引導／跟隨／待機管理器及唯一的速度命令仲裁。
- [ ] 加入獨立命令逾時看門狗、停用流程與重啟安全。
- [ ] 整合障礙停止、可選 collision_monitor 與恢復行為。
- [ ] 設計跟隨繞障策略，驗證各狀態切換及故障注入。

## 階段 5：穩健性與量測（2026 年 12 月–2027 年 1 月）

- [ ] 定義導航成功率、耗時、最小間距、跟隨誤差與停止延遲。
- [ ] 建立多種人物路徑、初始姿態及動態障礙情境。
- [ ] 使用 rosbag 記錄與回放，建立可重現的評估報告。
- [ ] 2027 年 1 月在 Mac、fish 與 Docker Desktop 逐條演練 README。

## 階段 6：硬體準備（2027 年 1 月）

- [ ] 確認 R2／筆電、CPU 架構、作業系統、介面及供電。
- [ ] 在 arm64 原生環境驗證容器，避免綁定特定板卡 SDK。
- [ ] 定義真實雷射、IMU、UWB、輪式里程計與底盤命令介面。
- [ ] 為未來驅動加入預設 false 的硬體選項與啟用文件。
- [ ] 設計含時間戳、錨點識別與有效性的 UWB 訊息；校正高度及時間同步。
- [ ] 確認實體急停、速度限制、裝置權限與安全測試場地。

## 階段 7：硬體驗證（2027 年 2 月）

- [ ] 人工監看下，先架空車輪驗證方向、停止及命令逾時。
- [ ] 校正雷射／IMU／UWB 安裝、TF、輪徑、輪距與里程計。
- [ ] 低速建圖、區域導航及跟隨，逐項通過安全測試。
- [ ] 比較模擬與實機指標，記錄差異並完成里程碑驗收。
